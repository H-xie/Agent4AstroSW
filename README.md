## What This Repository Contains

- Original notebook-based camera calibration workflow.
- Refactored, modular package for camera calibration in astronomy use cases.
- Unit and integration tests for reproducibility and regression protection.
- Verification and completion reports for documentation and publication support.

## Quick Start

### 1. Go to the package directory

```bash
cd sample/camera_calibration
```

### 2. Install dependencies

```bash
pip install -e .
```

### 3. Run tests

```bash
pytest tests/ -v
```

### 4. Run usage example

```bash
python examples/basic_usage.py
```

### 5. Generate verification report

```bash
python verify_refactoring.py
```
